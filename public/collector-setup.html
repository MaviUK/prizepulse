Connect your browser

That Prize Guy is denying requests from our hosting server. You can instead send the public ticket prices that appear in a page you open in your own browser. This does not use a private API or your account credentials.

Android setup

  1. Install Firefox for Android, then add Violentmonkey.
  2. In Firefox, tap Install PrizePulse browser connector and approve the userscript in Violentmonkey.
  3. Visit That Prize Guy's All competitions page. The PrizePulse widget will appear at the bottom. Tap Pair key, paste your private pairing key, and choose Start 1 min.
  4. Keep the Firefox tab visible while monitoring. The connector reads the public competition cards, sends those figures to PrizePulse, and reloads the visible page approximately every 60 seconds while enabled. You can stop it at any time.
How the data is labelled

These are browser-captured public listings, not independently verified server readings. The dashboard shows their capture time, identifies the source, and warns when captures are more than three minutes old.

Limitations

Android may suspend background tabs or lock the screen, so this is not guaranteed uninterrupted monitoring. If That Prize Guy refuses the page or its policies disallow this activity, stop the connector. The script does not bypass logins, challenges, access controls or rate limits, and it does not transmit your cookies, name, address or payment details.

For reliable unattended monitoring, the operator must allow an automated feed or server access. This option provides on-device monitoring of pages you can normally view.
